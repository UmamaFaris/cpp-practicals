# C++ Practicals

## Practical 02: Bank Account Management

### Aim
To implement a simple Bank Account Management system using C++ classes and objects.

### Concepts Used
- Classes and Objects
- Encapsulation
- Private and Public Members
- Constructors
- Member Functions
- Deposit and Withdrawal
- Display Account Details

### Description
This program creates a BankAccount class to manage bank account details.

It allows users to:
- Store account number and balance.
- Display account details.
- Deposit money.
- Withdraw money.
- Update account information.

### How to Run
1. Open `main.cpp`.
2. Compile the program.
3. Run the executable.

### Sample Output
```text
Account 1 Details:
Account Number: 101
Balance: 5000

Deposit successful!
Withdrawal successful!

Updated Account 1:
Account Number: 101
Balance: 5500

Account 2 Details:
Account Number: 102
Balance: 10000
```

### Conclusion
Successfully implemented a basic Bank Account Management system using C++ classes, objects and member functions.
