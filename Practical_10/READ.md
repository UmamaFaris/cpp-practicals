
# Practical 10: Custom Exceptions - Banking Transaction

## Aim
To understand custom exceptions and exception handling in C++.

## Description
This program implements a simple banking system
using custom exception classes.

It handles invalid withdrawal amounts and
insufficient account balance.

## Features
1. Bank account creation.
2. Money withdrawal.
3. Successful transaction handling.
4. Insufficient balance handling.
5. Invalid amount handling.

## Concepts Used
- Classes and Objects
- Inheritance
- Exception Handling
- try and catch
- throw keyword
- Custom Exceptions

## Exception Classes
- BankException: Base exception class.
- InsufficientFunds: Handles low balance.
- InvalidAmount: Handles invalid withdrawal amounts.

## How to Run

Compile:
g++ main.cpp -o main

Run:
.\main.exe

## Conclusion
Successfully implemented a banking transaction
program using custom exceptions in C++.
