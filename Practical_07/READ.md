
# Practical 07: Compile-Time Polymorphism

## Aim
To understand function overloading and operator overloading in C++.

## Concepts Used
- Compile-Time Polymorphism
- Function Overloading
- Operator Overloading
- Classes and Objects
- Complex Numbers

## Description
This program demonstrates function overloading
using two add() functions with different parameter types.

It also demonstrates operator overloading by
overloading the + operator for adding two complex numbers.

## Output
Integer Addition: 30
Double Addition: 10

First Complex Number: 10 + 5i
Second Complex Number: 5 + 3i
Addition Result: 15 + 8i

## How to Run

1. Open main.cpp.
2. Compile the program:

   g++ main.cpp -o main

3. Run the program:

   .\main.exe

## Result
Successfully implemented function overloading
and operator overloading in C++.
