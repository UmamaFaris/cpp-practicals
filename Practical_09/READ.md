
# Practical 09: Generic Stack Using Templates

## Aim
To understand generic programming using C++ templates.

## Description
This program implements a generic Stack class using templates and vector.

The same class is used with three different data types:
- Integer
- Float
- String

## Operations
1. push() - Adds an element.
2. pop() - Removes the top element.
3. top() - Displays the top element.
4. isEmpty() - Checks whether the stack is empty.

## Concepts Used
- C++ Templates
- Classes and Objects
- STL Vector
- Stack Operations

## How to Run

Compile:
g++ main.cpp -o main

Run:
.\main.exe

## Conclusion
Successfully implemented a generic Stack
using templates for integer, float and string values.
