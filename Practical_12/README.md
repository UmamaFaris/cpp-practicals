# 📚 Library Management System

### C++ Console-Based Mini Project

A simple and user-friendly Library Management System developed using C++. This project helps manage library books and perform basic library operations such as adding books, searching books, displaying book records, issuing books and returning books.

The project demonstrates the practical implementation of Object-Oriented Programming, STL, Exception Handling and File Handling in C++.

---

## 🎯 Project Objectives

- To develop a basic library management application.
- To understand Object-Oriented Programming concepts.
- To manage book records efficiently.
- To implement file handling for permanent data storage.
- To handle invalid operations using exception handling.
- To understand the use of STL containers in C++.

## ✨ Features

1. **Add Books:** Add new books with their details.
2. **Display Books:** View all available book records.
3. **Search Books:** Search for a book using its ID.
4. **Issue Books:** Issue a book from the library.
5. **Return Books:** Return previously issued books.
6. **File Handling:** Store and retrieve book records using CSV files.
7. **Input Validation:** Handle invalid inputs and operations.

## ⚙️ Installation and Execution

### Step 1: Install a C++ Compiler

Install MinGW or another C++ compiler and make sure it is configured in your system PATH.

### Step 2: Open the Project

Open the Practical_12 folder in Visual Studio Code.

### Step 3: Compile the Program

Open the VS Code terminal and execute:

```bash
g++ main.cpp -o main
```

### Step 4: Run the Program

On Windows PowerShell, execute:

```powershell
.\main.exe
```

## 💾 Data Storage

The application uses file handling to store and retrieve book records through a CSV file named `books.csv`.

This helps maintain book information between program executions.
