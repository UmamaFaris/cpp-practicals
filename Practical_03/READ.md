# C++ Practicals

## Practical 03: Copy and Move Constructors

### Aim
To understand and implement constructors, copy constructors, move constructors, copy assignment and move assignment in C++.

### Concepts Used
- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Move Constructor
- Copy Assignment Operator
- Move Assignment Operator
- Destructor
- Dynamic Memory Allocation

### Description
This program demonstrates different types of constructors and assignment operators using a dynamically allocated array.

It performs:
- Creation of an array.
- Copying an array using Copy Constructor.
- Assigning an array using Copy Assignment.
- Moving an array using Move Constructor.
- Moving an array using Move Assignment.
- Releasing allocated memory using Destructor.

### How to Run
1. Open `main.cpp`.
2. Compile the program.
3. Run the executable.
