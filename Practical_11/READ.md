
# Practical 11: CSV Student Records Using File I/O

## Aim
To understand file handling and file position functions in C++.

## Description
This program stores student records in a CSV file
and reads them back using file handling.

It also demonstrates four file position functions.

## Features
1. Stores three student records.
2. Writes records into students.csv.
3. Reads and displays student records.
4. Demonstrates file positioning.

## Concepts Used
- Classes and Objects
- File Handling
- fstream
- ifstream and ofstream
- CSV Files
- seekg()
- seekp()
- tellg()
- tellp()

## Files Generated
- students.csv
- position_demo.txt

## How to Run

Compile:
g++ main.cpp -o main

Run:
.\main.exe

## Conclusion
Successfully implemented CSV student records
using C++ file handling and demonstrated
seekg(), seekp(), tellg() and tellp().
